UNREAL ENGINE · CONTROL RIG

SMALL TOOL / FRESH

Looking at things
while running

Run cycles stare straight ahead, always. This Control Rig layer sits on top of the walk/run and turns everything from head to pelvis toward whatever deserves attention, without the legs ever finding out.

Every clip is the same sequence rendered twice with one value changed. It used to teleport from one shoulder to the other when the target crossed behind him. Now a custom slerp and a little helix-shaped U-turn handle that.

THE BIG ONE / STILL GOING

A creature with
simulated muscles

I wanted to know whether a creature could learn to stand using muscles instead of animation curves. So I wrote the physics solver. Then the muscle authoring tools and finally the PPO trainer so that I had everything in hand to start working.

It stands at full height now, but for walking, I'll need a bit more time (same for him, he's still a baby).

UNITY TOOLING

Pathfinding for things
that walk on ceilings

NavMesh assumes you have a floor. Ceiling-crawlers disagree. So I voxelised the whole volume instead, then optimised it so the grid wouldn't eat all the RAM.
