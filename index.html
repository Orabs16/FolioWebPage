THE BIG ONE / STILL GOING

A creature with
simulated muscles

I wanted to know whether a creature could learn to stand using muscles instead of animation curves. So I wrote the physics solver. Then the muscle authoring tools and finally the PPO trainer so that I had everything in hand to start working.

It stands at full height now, but for walking, I'll need a bit more time (same for him, he's still a baby).

// WHOAMI

I'd rather spend a week on the tool

I'm Corentin. Technical animator and tool programmer.

I like to make procedural systems for animation or just general-purpose ones. Diving into maths and logic to automate all sorts of things. And finding new ways to achieve our goals. Thanks to my internship at Ubisoft Annecy where I worked on procedural animation, I learned a lot about it but also about how AAA game companies work.

The other half of my job is making sure nobody else has to care about any of that. Creating tools that everyone can use.
